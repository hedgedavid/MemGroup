
Authors: David Hedge, Dakotah Williams, Dedi Seme, Haylee Staub

How to Run:
    Compile the isaSim.java file and run through the command line.
    Needs to be in format "$ isaSim <r|s> <assembly file> <memory file>"
        where r is to run through a file and s is to run through a file step by step
